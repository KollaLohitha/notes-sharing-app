# Notes Sharing App

A full-stack Notes Sharing Web Application that allows users to upload, manage, and access study notes securely. Built with React and Firebase, and deployed on Vercel.

---

## Live Demo
  https://notes-sharing-app-beta.vercel.app/
---

## Tech Stack

- React.js  
- Firebase (Authentication + Firestore + Storage)  
- Tailwind CSS  
- Vercel (Deployment)  
- Git & GitHub  

---

## Features

- User Authentication (Signup / Login)
- Upload study notes
- View uploaded notes
- Save and manage notes
- Organized dashboard
- Cloud storage with Firebase
- Responsive UI (Mobile + Desktop)

---

## Project Highlights

- Secure authentication system using Firebase  
- Real-time database integration  
- Cloud file storage system  
- Fully responsive UI design  
- Deployed with CI/CD using Vercel
